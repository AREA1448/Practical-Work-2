# Система «Коледж» — Об’єктно-орієнтоване програмування (Практична робота №2)

## Опис проєкту

Проєкт реалізує базову структуру класів предметної області **«Коледж»** мовою Java.

У рамках практичної роботи №2 створено класи, які описують основні сутності навчального закладу:

- **Person** — базова сутність (людина)
- **Student** — студент
- **Teacher** — викладач
- **Group** — навчальна група
- **Discipline** — дисципліна (предмет)
- **Grade** — оцінка
- **Journal** — журнал успішності

Кожен клас містить:
- поля (властивості)
- конструктори (за замовчуванням та з параметрами)
- методи з порожньою реалізацією (заготовки для подальшої розробки)
- перевизначений метод `toString()` для текстового представлення об’єкта
